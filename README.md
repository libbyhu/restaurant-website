# 波光の洋食館 (Restaurant Website)

A four-page static website for a Japanese-style Western restaurant (course project), built as an early course project (HTML, CSS, JavaScript, Bootstrap 5) and later cleaned up for my portfolio.

**Pages:** Home · About · Menu · Booking

## What I built
- Responsive layout with Bootstrap 5 (grid, navbar, cards)
- All illustrations are hand-drawn by me
- Booking form with HTML5 validation (phone-number pattern, email, required fields)
- Embedded Google Map, back-to-top button, auto-updating footer year

## Later improvements
- Fixed a broken script path and leftover template placeholders
- Compressed images (46 MB → about 9 MB) for faster mobile loading
- Descriptive page titles, `lang="zh-Hant"`, accessible map title
- Removed unused assets and unused Bootstrap source files

## Run locally
No build step. Open `index.html` in a browser.
